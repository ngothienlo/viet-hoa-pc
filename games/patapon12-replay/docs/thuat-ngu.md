# Thuật ngữ

Giữ nguyên tiếng gốc. Đây là tên riêng và âm nhịp, không dịch nghĩa.

## Nhịp trống

Pata, Pon, Don, Chaka.

Bốn tiếng này là lệnh người chơi gõ. Đổi chúng làm lệch nhịp với tiếng trống trong game.

## Tên giữ nguyên

| Gốc | Ghi chú |
| --- | --- |
| Patapon | Chủng tộc và tên game. |
| Hatapon | Đơn vị cầm cờ. |
| Yaripon | Giáo. |
| Tatepon | Khiên. |
| Yumipon | Cung. |
| Kibapon | Kỵ binh. |
| Dekapon | Đại đẩu. |
| Megapon | Kèn. |
| Mahopon | Phép. |
| Robopon | Cơ giới. |
| Toripon | Chim. |
| Zigoton | Phe đối đầu phần 1. |
| Karmen | Phe đối đầu phần 2. |
| Meden | Nữ tế. |
| Ban the Great | Tên giữ nguyên. |
| Gong | Thần trống. Có thể ghi «Gong». |

Khi cần giải thích vai trò, viết tên gốc rồi vai trò trong ngoặc ở lần xuất hiện đầu, ví dụ «Yaripon (giáo)». Các lần sau chỉ để tên gốc.
